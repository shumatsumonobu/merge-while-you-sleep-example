# merge-while-you-sleep-example

[merge-while-you-sleep](https://github.com/shumatsumonobu/merge-while-you-sleep) を導入した実行例のリポジトリ。Issue から PR、マージまでの実物を見るためのもの

- [Issues](../../issues?q=is%3Aissue) と [Pull requests](../../pulls?q=is%3Apr): Claude Code が書いた完了条件の下書き、承認の記録、作業の進捗、PR の本文
- [Actions](../../actions): 各ジョブのログ
- `src/strings.js`、`test/`: 小さい文字列のライブラリ。Issue から Claude Code が関数とテストを追加する
- `.github/workflows/`、`.github/ISSUE_TEMPLATE/`: merge-while-you-sleep の README の「導入」の手順どおりに置いたもの
